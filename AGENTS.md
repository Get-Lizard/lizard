# Lizard — agent guide

## Layout
- `project.yml` — XcodeGen spec (the `.xcodeproj` is generated, git-ignored).
- `App/` — SwiftUI + AppKit host (`LSUIElement` accessory app). `Model/` state, `Views/` UI.
- `Packages/LizardKit/` — UI-free modules:
  - `LizardCore` ProcessRunner, ToolEnvironment, AppPaths, LogRing, ResilientFile, HardwareProfile
  - `Search` app index, fuzzy matching, frecency, quicklinks
  - `Notes` markdown notes + work log stores, markdown tokenizer
  - `Clipboard` pasteboard monitor/filter, SQLite FTS5 history
  - `DevTools` port killer + text transformers
  - `AIEngine` provider protocol, cloud clients, Apple Foundation Models (ported from Cocoon)
  - `AIEngineMLX` local MLX models (separate so CLI/tests don't need Metal)
  - `ExtensionHost` Raycast-compatible extension runtime (Swift side) + `js/` shim (TypeScript)
  - `lizardcli` headless CLI

## Build, test, run
```
cd Packages/LizardKit && swift build && swift test
xcodegen generate
xcodebuild -project Lizard.xcodeproj -scheme Lizard -configuration Release -derivedDataPath DerivedData -destination 'platform=macOS,arch=arm64' -skipMacroValidation build
cd Packages/LizardKit/Sources/ExtensionHost/js && npm install && npm run build && npm test
```
Release builds for real use: MLX is very slow in Debug. Each machine needs `xcodebuild -downloadComponent MetalToolchain` once.

## Conventions
- Swift 6 language mode, `SWIFT_STRICT_CONCURRENCY: complete`.
- `@Observable @MainActor final class` for UI state; `actor` for engines; value types `Sendable`.
- Tests use Swift Testing (`@Suite`, `@Test`, `#expect`). Parsers, matchers and transformers need tests.
- Errors: per-module `enum …Error: Error, LocalizedError`.
- UserDefaults keys: `Lizard.*`.
- Never read the Keychain in a view body (use `Keychain.cachedValue`).

## Decisions
1. Non-sandboxed: CGEvent paste, Accessibility, `lsof`, Node subprocess.
2. Local AI = MLX (mlx-swift-lm 3.31.4 pinned exact) + Apple Foundation Models; cloud is opt-in.
3. Default launcher hotkey ⌃Space (conflicts with "previous input source" — setup warns).
4. Raycast extensions run in a bundled/user Node with a `@raycast/api` shim built on `react-reconciler`; the view tree is sent to Swift over NDJSON on stdio and rendered natively.
5. Clipboard ignores `org.nspasteboard.ConcealedType`/`TransientType`/`AutoGeneratedType`.

## Known pitfalls
- The launcher `NSPanel` must override `canBecomeKey` → true, or typing doesn't work in a non-activating panel.
- GUI apps get a minimal PATH; resolve tools via `ToolEnvironment.shared.which`.
